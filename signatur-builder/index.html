Signatur-Builder

Angaben eintragen – unten entsteht deine fertige E-Mail-Signatur zum Kopieren.

1Deine Angaben

2Deine Signatur

3Im Mailprogramm einfügen

  1. Outlook neu / Web: Einstellungen → Konten → Signaturen → Neue Signatur → einfügen → Speichern
  2. Outlook klassisch: Datei → Optionen → E-Mail → Signaturen → Neu → einfügen
  3. Outlook Mac: Outlook → Einstellungen → Signaturen → + → einfügen
  4. Gmail: Zahnrad → Alle Einstellungen → Allgemein → Signatur → Neu → einfügen → unten speichern
  5. Apple Mail: Einstellungen → Signaturen → + → einfügen, Haken «Immer meine Standardschrift verwenden» entfernen

Tipp: Danach eine Testmail an dich selbst schicken.
